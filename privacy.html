Privacy policy

Co-Driver · last updated 8 October 2026

Co-Driver is a private personal assistant used by one person, its user. This page explains what it does with Google user data.

What Co-Driver accesses

With the user's permission, given on Google's consent screen, Co-Driver reads and manages the user's Gmail (to read messages and send emails the user approves) and Google Calendar (to read events and create invitations the user approves).

How it is used

  • Only to provide the assistant to its user: summaries, reminders, drafts and an overview of the people they know.
  • Nothing is sent or created without the user's explicit approval on their own device.
  • The data is never sold, never used for advertising, and never shared with anyone except the service providers that run the assistant for the user (hosting, encrypted backups, and the AI model provider that processes text on the user's behalf).
  • No human reads the user's data, except with the user's permission, for security purposes, or where the law requires it.

Google API Services User Data Policy

Co-Driver's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and deletion

Data is stored encrypted on a server in the United States. Message text is kept for 90 days. The user can disconnect Google at any time, which deletes the data that came from it, or delete everything. Access can also be revoked at myaccount.google.com/permissions.
